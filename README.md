# ShopNest - MERN E-Commerce Store

## Overview

ShopNest is a full-stack MERN E-Commerce application that allows users to browse products, add items to cart, manage wishlist, place orders, and track order status.

## Features

### User Features

* User Registration & Login
* Product Listing
* Product Details Page
* Search Products
* Category Filter
* Shopping Cart
* Wishlist Management
* Place Orders
* Order History

### Admin Features

* Admin Dashboard
* View All Orders
* Update Order Status
* Manage Orders

## Tech Stack

### Frontend

* React.js
* React Router
* Tailwind CSS
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB Atlas
* Mongoose
